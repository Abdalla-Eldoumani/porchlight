Setup

Connect the services

Every key here is optional. With none at all, the demo still runs: the replay uses the real 2024 data, messages use a template and data stays in memory. Paste a key, press Test, then Save. Keys are never written into the project's files.

Gemini

Writes each volunteer's message in plain words and in their language (Yusuf reads Arabic, Mei reads Chinese). The rules still decide who is asked.

MLH · Gemini API
  1. Open aistudio.google.com/apikey and sign in.
  2. Create API key, copy it, paste it here.
  3. If the test says the model wasn't found, type gemini-2.5-flash as the model.

Tiger Data

Stores the grid readings and every button press in TimescaleDB, and draws the chart from it.

MLH · Tiger Data
  1. Open console.cloud.tigerdata.com and create a free service.
  2. Copy its connection string (it ends in ?sslmode=require) and paste it here.
  3. Saving moves the app onto the database straight away. The tables are created for you.

AESO live data

The replay already uses real AESO data. This key adds Live now: Alberta's demand and supply cushion as they are today.

Voltex · real energy data
  1. Open developer-apim.aeso.ca and sign up.
  2. Under Products, open AESO Public API and subscribe. Your Profile then shows the subscription's primary key: copy it and paste it here.

Auth0 sign-in

Makes coordinators sign in before they can see anyone's status. Turn this on last, and test it on localhost first, or you can lock yourself out of your own demo.

MLH · Auth0
  1. In manage.auth0.com, create an Application of type Single Page Application.
  2. Allowed Callback and Logout URLs: . Allowed Web Origins: .
  3. Create an API with the identifier https://porchlight-api and use that as the audience.

The real box

A shared key so only your Arduino can press buttons for Margaret. Put the same value in the box's device_config.json.

With a box key set, the on-screen box page needs ?key=… in its address. The demo screen keeps working without it.
